«Де моя посилка?» — найчастіше питання в будь-якому інтернет-магазині. Менеджер відкриває замовлення, копіює ТТН, вставляє на сайті Нової пошти, копіює статус назад у чат. Дві-три хвилини на кожне звернення, десятки разів на день. Telegram-бот з інтеграцією Нової пошти робить це за секунду. Розповідаємо, як це влаштовано зсередини.

## Як працює Telegram-бот з API Нової пошти

Схема в найпростішому вигляді:

1. Клієнт пише боту номер ТТН, номер замовлення або телефон.
2. Бот знаходить ТТН — напряму або через замовлення в магазині (Shopify, WooCommerce, CRM).
3. Бот запитує статус в API Нової пошти.
4. Бот відповідає людською мовою: де посилка, коли прибуде, скільки днів безкоштовного зберігання лишилось.

Найважливіше тут — пункт 2. Клієнти майже ніколи не пам'ятають номер ТТН, зате завжди знають свій телефон.

## Запит статусу ТТН через API Нової пошти

API Нової пошти — це JSON-запити на єдину адресу з указанням моделі й методу. Для статусу посилки використовується модель трекінгу документів:

```json
{
  "apiKey": "ВАШ_КЛЮЧ",
  "modelName": "TrackingDocument",
  "calledMethod": "getStatusDocuments",
  "methodProperties": {
    "Documents": [
      { "DocumentNumber": "20450000000000", "Phone": "380670000000" }
    ]
  }
}
```

Що важливо знати з практики:

- **Телефон у запиті** відкриває розширені дані. Без нього повертається лише базовий статус.
- **За один запит можна перевірити кілька ТТН** — так економимо ліміти, коли бот перевіряє всі активні відправлення.
- **У відповіді є числовий код статусу і текст.** Логіку бота будуйте на коді, а не на тексті — текст може змінюватися.
- **Дати й відділення** повертаються окремими полями — з них бот складає людську відповідь, а не показує «сирий» статус.

## Пошук замовлення за телефоном: інтеграція з магазином

Щоб бот знаходив посилку за телефоном, він має доступ до замовлень:

- **Shopify** — пошук замовлень за телефоном клієнта через Admin API, а ТТН береться з поля трекінгу відправлення.
- **WooCommerce** — через REST API і мета-поле, куди плагін доставки записує номер ТТН.
- **CRM** (KeyCRM, SalesDrive, Bitrix24 тощо) — через їхні API.

Якщо ТТН у вас створюються автоматично при оплаті — як у наших інтеграціях Shopify → Нова пошта — номер одразу записується в замовлення, і бот завжди має свіжі дані.

## Сповіщення про прибуття посилки

Найцінніша функція — бот пише сам, не чекаючи питання:

- *«Посилка відправлена, ТТН 2045…, орієнтовна дата — четвер»*;
- *«Посилка прибула у відділення №12. Безкоштовне зберігання — до суботи»*;
- *«Посилка чекає вже 4 дні — завтра останній день безкоштовного зберігання»*.

Останнє повідомлення помітно зменшує кількість повернень через неотримання, а для магазинів з накладеним платежем це прямі гроші.

Технічно: бот за розкладом перевіряє всі активні ТТН і порівнює статус із попереднім. Пам'ятайте обмеження Telegram — бот пише лише тим, хто натиснув «Старт». Тому посилання на бота дайте на сторінці «Дякуємо за замовлення», у SMS чи листі з підтвердженням.

## AI чи кнопки: як бот розуміє клієнта

- **Кнопковий варіант**: «Відстежити посилку» → «Введіть телефон» → статус. Надійно й дешево.
- **AI-варіант**: клієнт пише як хоче — *«замовляла в понеділок сукню, де вона?»* — бот сам витягує телефон, знаходить замовлення і відповідає. Плюс відповідає на суміжні питання: обмін, повернення, умови зберігання.

Для магазину з десятками звернень на день ми зазвичай радимо AI-варіант із кнопками-підказками: клієнт може і натиснути, і написати.

## Типові помилки інтеграції з Новою поштою

1. **API-ключ у фронтенді.** Ключ має жити лише на сервері.
2. **Опитування кожної ТТН окремим запитом кожні 5 хвилин.** Пакетні запити й розумний інтервал — інакше впретеся в ліміти.
3. **Логіка на тексті статусу.** Текст змінюється — використовуйте коди.
4. **Немає обробки збоїв.** API іноді не відповідає — бот має показати останній відомий статус і повторити запит пізніше.
5. **Бот не знає про повернення й переадресацію.** Це окремі статуси, і на них потрібні окремі відповіді.

Ключ до успіху — пошук за телефоном через інтеграцію з магазином і проактивні сповіщення.
